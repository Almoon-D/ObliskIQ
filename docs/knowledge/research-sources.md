# Research data sources

What the research loaders (`src/obliskiq/research/data.py`) read from each vendor, as seen when
the fixtures in `tests/fixtures/research/` were recorded. The endpoints are configuration
(`config/defaults/research.yaml`); this file records their observed formats and what they do
not promise.

| Vendor | Observed | Point in time |
|---|---|---|
| Yahoo through `yfinance` 1.7.0 | `Ticker(...).history(auto_adjust=False, actions=True)` returns a frame indexed by the session's timestamp at midnight in the exchange's zone (`Europe/Berlin` for `EUNL.DE`, `America/New_York` for `SPY`), with `Open`, `High`, `Low`, `Close`, `Adj Close`, `Volume`, `Dividends`, `Stock Splits`, `Capital Gains`; `Close` is split-adjusted, `Adj Close` also dividend-adjusted; an accumulating fund's two closes are equal. A direct `curl` to Yahoo's chart endpoint answered HTTP 429; `yfinance` warned that its crumb fetch was rate limited and still served the history `[Yahoo ✓ 2026-10-16]` | as observed (the close of its session); not point in time across splits or dividends, which re-scale history backwards |
| Ken French data library | a zip holding one CSV: free-text header lines, then tables that each open with a row starting with a comma (`,Mkt-RF,SMB,HML,RF`) and end at a blank line; the first is monthly (`YYYYMM`), the second annual (`YYYY`); values in percent; the file names the CRSP vintage it was built from ("created using the 202608 CRSP database"); missing values are `-99.99` or `-999` in the portfolio files `[Dartmouth ✓ 2026-10-16]` | revised without vintages; availability is a declared lag |
| AQR data sets | an `.xlsx` workbook; the data sheet (`TSMOM Factors`) has notes above a header row (row 18), Excel serial dates in column A (1900 system: 31078 is 1985-01-31) and decimal excess returns; other sheets hold definitions and disclosures `[AQR ✓ 2026-10-16]` | revised without vintages; availability is a declared lag |
| FRED | `fredgraph.csv?id=<series>`: header `observation_date,<series>`, one row per observation, `.` for a missing value; the latest revision only `[FRED ✓ 2026-10-16]` | a declared lag after the observation date |
| ALFRED | `fred/series/observations` with `realtime_start` and `realtime_end` (and `FRED_API_KEY`): one row per observation and vintage with `date`, `value`, `realtime_start`, `realtime_end`; UNRATE for October 2023 was first published at 3.9 on 2023-11-03 and revised to 3.8 on 2024-01-05. The answer does not echo the key `[ALFRED ✓ 2026-10-16]` | vintages: each value public from its `realtime_start` |
| ECB reference rates | `eurofxref-hist.zip`: one CSV, newest date first, a trailing comma on every row, units of each currency per euro, `N/A` for a currency not fixed (legacy currencies); no row on TARGET holidays (Good Friday and Easter Monday 2024 are absent) `[ECB ✓ 2026-10-16]` | as observed (published around 16:00 CET on its day) |
| MSCI end-of-day index levels | `getLevelDataForGraph?currency_symbol=EUR&index_variant=NETR&start_date=YYYYMMDD&end_date=YYYYMMDD&data_frequency=DAILY&index_codes=990100` answers JSON (`msci_index_code`, `index_variant_type`, `ISO_currency_symbol`, `indexes.INDEX_LEVELS[]` of `calc_date` as the integer YYYYMMDD and `level_eod`); a start before 1997-01-01 is refused with `error_code` 100; levels begin on 2000-12-29 whatever the start asked for, for World (990100), Emerging Markets (891800) and ACWI (892400) in EUR and USD; calculation days include weekday holidays (1 January 2024 has a level) `[MSCI ✓ 2026-10-17]` | as observed (the end of each calculation day); restated without vintages |
| ECB Data Portal | `data-api.ecb.europa.eu/service/data/<flow>/<key>?format=csvdata` answers one CSV row per period with `KEY`, `TIME_PERIOD`, `OBS_VALUE` and quoted metadata columns; EONIA (`EON/D.EONIA_TO.RATE`) runs from 1999-01-04 to 2021-12-31, the euro short-term rate (`EST/B.EU000A2X2A25.WT`) from 2019-10-01; the AAA yield curve (`YC/B.U2.EUR.4F.G_N_A.SV_C_YM.SR_10Y`) from 2004-09-06 `[ECB ✓ 2026-10-17]` | as observed (EONIA in the evening of its day; the euro STR at 08:00 the next TARGET day) |
| Bundesbank time-series database | `api.statistiken.bundesbank.de/rest/data/BBSIS/D.I.ZST.ZI.EUR.S1311.B.A604.R<NN>XX.R.A.A._Z._Z.A?format=csv&lang=en`: a byte-order mark, a header naming the series, metadata rows (unit `Prozent`), then `YYYY-MM-DD,value,flag` with `.` and "No value available" on days without one; residual maturities of 1 to 20 years from 1997-08-07, 25 and 30 years from 2000-08-01. The rates are zero-coupon and continuously compounded: the 1-, 5- and 10-year rates of 2026-10-05 (2.91, 3.18, 3.51) equal the Svensson formula of that day's published parameters (β0 4.15209, β1 −1.89415, β2 0.00541, β3 −2.72620, τ1 0.46454, τ2 2.16227) to two decimals `[Bundesbank ✓ 2026-10-17]` | as observed (estimated from the day's closing prices; published afterwards) |
| Yahoo, European listings | the histories of `EUNL.DE`, `IWDA.AS`, `IQQW.DE`, `IWRD.L` and the iShares and Lyxor euro bond lines on Xetra, Amsterdam and Paris start in 2008–2009 whatever the fund's launch; `XMWO.DE` and `MTX.PA` are not found; `CRSOX` is now the Cantor Fitzgerald (formerly Credit Suisse) Commodity Return Strategy Fund, from 2004-12-31; `^SPGSCI` is the S&P GSCI headline index from 1990 (which variant was not established, so it is not used) `[Yahoo ✓ 2026-10-17]` | as observed |
| Fund metadata | Yahoo's `netExpenseRatio` (percent) on 2026-10-17: EUNL 0.20, EUNM 0.18, CBE7 0.20, IBGL 0.20, XEON 0.10, IUST 0.10, SXRM 0.07, CMOD 0.19; `totalAssets` (USD) where served: EUNM 10.49 bn, IS3N 46.80 bn, VGVF 11.61 bn, VFEM 5.99 bn, CBE7 1.35 bn, IBGL 1.01 bn, SXRM 4.94 bn, XEON 24.20 bn. iShares' product page gave IWDA's net assets as USD 151.80 bn and its total expense ratio as 0.20 % on 16 October 2026 `[Yahoo ✓ 2026-10-17]` `[iShares ✓ 2026-10-17]` | metadata, read once |
| Refused | `prices.lbma.org.uk` (LBMA gold prices) answered HTTP 403 and stooq reset the connection from the cloud container `[2026-10-17]` | — |
